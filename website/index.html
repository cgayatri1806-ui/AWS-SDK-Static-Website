Deployment Workflow

From Local Files to Amazon S3

How the website moves from local development to a live endpoint.

  1. Create an S3 bucket in the Mumbai region.
  2. Prepare HTML and other website files locally.
  3. Use Python and Boto3 to upload website files.
  4. Configure S3 static website hosting.
  5. Open the website endpoint and verify deployment.
Project objective
Reduce repetitive manual uploads with a reusable Python deployment script.
